# Фрукты&Ко — учебный интернет-магазин

## Описание

Многостраничный сайт магазина фруктов. Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка» (контрольная работа №1: «HTML и CSS: разработка многостраничного сайта»).

## Страницы

- `index.html` — главная: hero, преимущества, популярные фрукты, модальное окно заявки;
- `catalog.html` — каталог из 6 товаров;
- `product-apple.html`, `product-banana.html` и т.д. — страницы товаров (6 штук);
- `order.html` — страница оформления заявки;
- `contacts.html` — контакты.

## Структура проекта

- `css/style.css` — стили (переменные, БЭМ-классы, Flex/Grid, адаптивность);
- `js/main.js` — модальное окно и отправка формы заявки;
- `images/` — папка для изображений;
- `.gitignore`, `README.md`.

## Используемые технологии

HTML5 (семантика), CSS3 (Flex, Grid, переменные), JavaScript (минимально), Git, GitHub Pages.
